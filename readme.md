## 🧱 Architecture

This project follows a modular SCSS structure inspired by the 7-1 pattern for scalability and maintainability.

scss/
├── abstracts/   # variables, mixins, functions  
├── base/        # reset, typography  
├── components/  # buttons, cards, form elements  
├── layout/      # hero, header, footer, grid  
├── section/     # section-specific styles  
├── vendors/     # external styles  
└── main.scss  

---

## 📱 Features

* Fully responsive layout (mobile, tablet, desktop)
* Hero section with responsive grid adaptation
* Project cards with hover overlay interactions (desktop)
* Contact form with validation states (CSS-based)
* SCSS mixins and breakpoint system using Sass maps
* Clean BEM methodology for class naming
* CSS pseudo-elements for decorative elements

* Handling stacking context (z-index, overlays, pseudo-elements)
* Improving UI interactions (hover, active, focus states)
* Structuring scalable component-based CSS
